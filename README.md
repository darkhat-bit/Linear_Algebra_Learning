## 🌟 Featured Core Implementations

### 🤖 1. End-to-End Recommendation Engine
* **Location:** `projects/01_movie_recommendation_system_cosine_similarity.py`
* **Concepts:** Feature engineering, Min-Max normalization, multi-label categorical grouping, and Vector Space Modeling using `scikit-learn` Cosine Similarity.
* **Outcome:** Recommends the highest matching items based on user consumption historical indices and outputs an analytical performance dashboard (`movie_recommendation_analysis.png`).

### 🚚 2. Greedy TSP Route Optimizer
* **Location:** `matplotlib/05_delivery_route_optimizer_greedy_algo.py` & `projects/06_greedy_tsp_route_optimizer_numpy.py`
* **Concepts:** Euclidean Distance Matrices, Linear Dependency validation, and nearest-neighbor search logic.
* **Outcome:** Simulates an industry-grade path routing mechanism, rendering dynamic directional spatial arrow traces on top of custom heatmaps.

### 🧠 3. Advanced Low-Level Memory Manipulation
* **Location:** `numpy/08_numpy_manual_stride_traversal_using_ctypes.py`
* **Concepts:** Memory layout strides, C-types execution, and hardware byte-offset calculation formulas.
* **Outcome:** Manually extracts exact cell indices from raw hardware memory addresses without standard Python frameworks, replicating low-level tensor engine optimization mechanisms.

### 🧠 4. NumPy Neural Network Layer Engine & Dashboard
* **Location:** `projects/07_neural_network_layer_engine.py`
* **Concepts:** Linear Transformations ($X \cdot W$), Matrix Dimension Alignment ($3\times4 \cdot 4\times5 \rightarrow 3\times5$), non-linear ReLU Activation execution via vectorized logic, and complex layout orchestration using `subplot2grid`.
* **Outcome:** Simulates a deep learning hidden layer's forward pass from scratch, mapping input distributions, weights tensors, and activated outputs onto a unified matrix-visualization dashboard.
